# نور (Nour)

تطبيق Flutter للصلاة والإسلام: مواقيت وأذان، قبلة، متتبّع صلوات، مصحف (بحث، علامات، تفسير، قرّاء، ختمة)، أذكار وأدعية ومسبحة، زكاة، تقويم هجري، ووضع رمضان التلقائي. يدعم العربية والإنجليزية والفرنسية، والوضع الداكن ولون التمييز.

## التشغيل

```bash
bash tool/setup.sh     # يولّد مجلد android ويضبط الأذونات والأيقونة
flutter run
```

يتطلب Flutter 3.22+ (Dart ≥ 3.4). الإنترنت مطلوب للمصحف والتفسير والصوت.

## ملاحظات صريحة

- **لم يُجمَّع الكود ولم يُختبر.** كُتب بدون Flutter في بيئة البناء. توقّع بعض أخطاء الترجمة أو الواجهة عند أول `flutter analyze`؛ أصلحها أو أرسلها لي.
- **نصوص الأذكار والأدعية** (`lib/data/adhkar.dart`) كُتبت من الذاكرة، فراجعها على مصدر موثوق قبل النشر.
- **التقويم الهجري** حسابي (جدولي) وقد يختلف يومًا عن الرؤية؛ يوجد تعديل ±2 في الإعدادات.
- **زكاة الفطر**: المقدار يدخله المستخدم بحسب جهة الإفتاء في بلده.
- **الزجاج** في شريط التنقل تقريب بـ BackdropFilter. الانكسار الحقيقي يحتاج fragment shader (عمل مستقبلي).
- اسم المطوّر يظهر في الإعدادات فقط.

## المصادر

القرآن والتفسير: api.alquran.cloud (`quran-uthmani`, `ar.muyassar`). الصوت: cdn.islamic.network. حساب المواقيت: حزمة `adhan`.
